======================================================
PASTA DE MODELOS 3D DOS PLANETAS (.GLB) - StarshipX
======================================================

Você pode colocar seus modelos 3D (.glb) do Sistema Solar aqui.
O jogo suporta tanto modelos individuais para cada planeta
quanto um modelo completo com todo o Sistema Solar!

OPÇÃO A - Planetas Individuais:
- sun.glb          -> Modelo 3D do Sol
- mercury.glb      -> Modelo 3D de Mercúrio
- venus.glb        -> Modelo 3D de Vênus
- earth.glb        -> Modelo 3D da Terra
- mars.glb         -> Modelo 3D de Marte
- jupiter.glb      -> Modelo 3D de Júpiter
- saturn.glb       -> Modelo 3D de Saturno
- uranus.glb       -> Modelo 3D de Urano
- neptune.glb      -> Modelo 3D de Netuno

OPÇÃO B - Sistema Solar Completo (em 1 único arquivo):
- solar_system.glb -> Se você tem o sistema solar inteiro em um único arquivo .glb!

Se os arquivos estiverem no Google Drive:
- Você pode baixar o(s) arquivo(s) .glb do Drive e anexar/arrastar aqui no chat;
- Ou colar o link de compartilhamento do Drive aqui para integrarmos!
