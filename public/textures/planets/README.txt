===========================================================
PASTA DE TEXTURAS DOS PLANETAS DO SISTEMA SOLAR (StarshipX)
===========================================================

Você pode colocar as imagens (.jpg ou .png) dos planetas aqui
com os seguintes nomes para que o jogo as carregue automaticamente:

- sun.jpg          -> Textura do Sol
- mercury.jpg      -> Textura de Mercúrio
- venus.jpg        -> Textura de Vênus
- earth.jpg        -> Textura da Terra
- mars.jpg         -> Textura de Marte
- jupiter.jpg      -> Textura de Júpiter
- saturn.jpg       -> Textura de Saturno
- saturn_ring.png  -> Textura dos anéis de Saturno (transparente)
- uranus.jpg       -> Textura de Urano
- neptune.jpg      -> Textura de Netuno

Se as suas imagens estiverem no Google Drive:
1. Você pode baixá-las para seu computador e enviá-las aqui no chat ou copiar para esta pasta.
2. Ou pegar o link de compartilhamento de cada arquivo no Google Drive e nos fornecer para vincularmos direto no código!
